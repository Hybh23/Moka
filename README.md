# موكا للخدمات التموينية — Moka Kitchen

موقع الشركة + الهوية البصرية + لوحة إدارة كاملة. الطلبات والحجوزات كلها تمشي على **واتساب**.

## شنو فيه

**الهوية البصرية** في مجلد `brand/`:
- `Moka-Brand-Guidelines.pdf`: دليل الهوية (الشعار، النسخ، المساحة الآمنة، الممنوعات، الألوان، الخطوط، العناصر، التطبيقات)
- `Moka-Brand-Assets.zip`: ملفات الشعار الجاهزة (SVG و PNG) مع الدليل
- لإعادة توليد الدليل بعد أي تعديل: `node scripts/build-guidelines.js` ثم افتح `brand/guidelines.html` واطبعه PDF (A4 أفقي)

**الموقع** (نسخة عرض أولية لصاحب الشركة):
- الصفحة الرئيسية: الواجهة، أصناف من المنيو، الباقات، مواعيد التذوّق، صور الأعمال، التواصل
- صفحة المنيو `/menu`: الأصناف مقسّمة حسب الأقسام، مع بحث
- المعلومات الحقيقية مأخوذة من صفحة الشركة على فيسبوك فقط: الاسم، الجملة التعريفية، الهواتف، العنوان، الخريطة، "مفتوح دائمًا"، والصور
- كل الباقي (أسماء الأصناف، الأسعار، الباقات، مواعيد التذوّق) **أماكن فاضية** تبيّن الشكل فقط، وتتعدّل أو تتحذف من اللوحة. فيه زر في اللوحة يحذفهم كلهم مرة وحدة

**الطلب:** الزبون يزيد الأصناف للطلبية، يكتب اسمه وتاريخ المناسبة، ويضغط "إرسال الطلب على واتساب". تفتح محادثة واتساب فيها الطلب كامل. نفس الشي لطلب الباقة وحجز التذوّق. وكل طلب يتسجّل زادة في "الطلبات" في اللوحة.

**لوحة الإدارة** على `/admin`:
- محتوى الموقع: الأصناف، أقسام المنيو، الباقات، مواعيد التذوّق، صور الأعمال
- الطلبات: كل طلب بحالته (جديد، تم التواصل، تم التنفيذ، ملغي) وزر "راسله"
- معلومات الشركة: الاسم، الجملة التعريفية، الصورة الرئيسية، واتساب، الهواتف، العنوان، الخريطة، السوشيال، مواعيد العمل
- النسخ الاحتياطي، وتغيير كلمة السر

الصور المرفوعة تتصغّر وتتحوّل لـ WebP وحدها.

## التشغيل على جهازك

يحتاج Node.js 18 أو أحدث.

```bash
npm install
ADMIN_PASSWORD='كلمة-سر-قوية' npm start
```

افتح `http://localhost:3000` للموقع، و `http://localhost:3000/admin` للوحة.

## الرفع على سيرفر

### بـ Docker (الأسهل)

```bash
docker build -t moka .
docker run -d --name moka -p 80:3000 \
  -e ADMIN_PASSWORD='كلمة-سر-قوية' \
  -e SITE_URL='https://moka.ly' \
  -v moka-data:/data \
  --restart unless-stopped moka
```

كل البيانات والصور تتخزن في `/data` (المجلد `moka-data`). **احتفظ بنسخة منه**، هذا هو كل محتوى الموقع.

### على أي استضافة Node (Render, Railway, VPS...)

- أمر التشغيل: `npm start`
- لازم **قرص دائم** (Persistent Disk) تربطه وتحط مساره في `DATA_DIR` و `UPLOAD_DIR`، وإلا التعديلات تضيع مع كل إعادة تشغيل.
- حط الدومين خلف HTTPS (Cloudflare أو Caddy أو Nginx).

### متغيرات التشغيل

| المتغير | الاستخدام |
|---|---|
| `ADMIN_PASSWORD` | كلمة سر اللوحة أول مرة. بعدها تقدر تغيّرها من اللوحة. لو ما حطيتهاش، أول واحد يفتح `/admin` هو اللي يحددها، فحطها قبل ما تنشر الموقع |
| `SITE_URL` | رابط الموقع الكامل (مثال `https://moka.ly`)، لجوجل وروابط المشاركة |
| `PORT` | المنفذ (الافتراضي 3000) |
| `DATA_DIR` | مكان ملف البيانات (الافتراضي `./data`) |
| `UPLOAD_DIR` | مكان الصور المرفوعة (الافتراضي `./uploads`) |

## قبل الإطلاق

1. من اللوحة: عبّي الأصناف والأسعار والباقات ومواعيد التذوّق الحقيقية، أو احذف الأماكن الفاضية.
2. ارفع صور أصلية بجودة عالية. الصورتين الحاليتين مقصوصات من سكرين شوت الفيسبوك ودقتهم ضعيفة.
3. أكّد رقم واتساب اللي توصله الطلبات (معلومات الشركة ← التواصل).
4. لو عند المصمم الأصلي ملف الشعار (AI أو SVG)، طابق الرسم عليه.

```

src/api.js           واجهة البيانات ورفع الصور
src/store.js         التخزين (ملف JSON مع نسخ احتياطية)
src/auth.js          الدخول للوحة
src/seed.js          محتوى البداية
src/mark.js          الشعار (SVG)
public/css, js       تصميم وتفاعل الموقع
public/admin         لوحة الإدارة
public/brand         ملفات الشعار والأيقونات
brand/               دليل الهوية PDF وملفات الشعار
scripts/build-brand.js       يعيد توليد ملفات الشعار: npm run brand
scripts/build-guidelines.js  يعيد توليد دليل الهوية
```
